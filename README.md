# ČeskáVesnice.cz

Modern landing page for **ČeskáVesnice.cz - digitální krajinná kronika**.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS

## Development

Install dependencies and start the local site:

```bash
npm install
npm run dev
```

The app is intentionally frontend-only for now: no database, no backend, no login, no Supabase.
